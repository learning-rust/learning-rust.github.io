## Database Design

> [!tip]
> - To keep this series simple, we use only a single Postgres database table named `books`.
> - We order fixed-width table columns by decreasing alignment requirements to optimize using Column Tetris.
> - We map `TIMESTAMPTZ`, `DATE`, `UUID` types to `jiff::{Timestamp, civil::Date}`, `uuid::Uuid` Rust types.

| Column Name    | Datatype    | Not Null | Primary Key |
|----------------|-------------|----------|-------------|
| created_at     | TIMESTAMPTZ | ✅       |             |
| updated_at     | TIMESTAMPTZ | ✅       |             |
| id             | UUID        | ✅       | ✅          |
| published_date | DATE        | ✅       |             |
| status         | SMALLINT    | ✅       |             |
| title          | TEXT        | ✅       |             |
| description    | TEXT        |          |             |
| image_url      | TEXT        |          |             |

## Initial Model

### Add Initial `book.rs`

Add a new file `book_service/src/models/book.rs`.

```rust
use jiff::{Timestamp, civil::Date};
use uuid::Uuid;

#[derive(Debug, toasty::Model)]
pub struct Book {
    #[auto]
    pub created_at: Timestamp,

    #[auto]
    pub updated_at: Timestamp,

    #[key]
    #[auto]
    pub id: Uuid,

    pub published_date: Date,

    pub status: BookStatus,

    pub title: String,

    pub description: Option<String>,

    pub image_url: Option<String>,
}

#[derive(Debug, Clone, Copy, PartialEq, toasty::Embed)]
#[column(type = u8)]
pub enum BookStatus {
    #[column(variant = 0)]
    Pending,
    #[column(variant = 1)]
    Verified,
}
```

### Update `config.rs`

Update `book_service/src/config.rs` to add `DbConf`.

```rust
use envconfig::Envconfig;
#[derive(Envconfig)]
pub struct AppConf {
    #[envconfig(nested)]
    pub server: ServerConf,

    #[envconfig(nested)]
    pub db: DbConf,
}

// impl AppConf and ServerConf

#[derive(Envconfig)]
pub struct DbConf {
    #[envconfig(from = "DB_PROTOCOL", default = "postgres")]
    pub protocol: String,
    #[envconfig(from = "DB_HOST")]
    pub host: String,
    #[envconfig(from = "DB_PORT", default = "5432")]
    pub port: u16,
    #[envconfig(from = "DB_USER")]
    pub user: String,
    #[envconfig(from = "DB_PASS")]
    pub password: String,
    #[envconfig(from = "DB_NAME")]
    pub db_name: String,
}

impl DbConf {
    pub fn init() -> Self {
        Self::init_from_env().expect("Failed to load configuration! Check the .env file.")
    }

    pub fn to_database_url(&self) -> String {
        format!(
            "{}://{}:{}@{}:{}/{}",
            self.protocol, self.user, self.password, self.host, self.port, self.db_name
        )
    }
}
```

### Re-exporting `DbConf` Struct

Update `book_service/src/lib.rs` to re-export `DbConf`.

## Migration CLI

### Add Migration CLI

Add a new file `book_service/src/bin/migration.rs`.

```rust
use book_service::{DbConf, models::*};
use toasty_cli::{Config, ToastyCli};

#[tokio::main]
async fn main() -> anyhow::Result<()> {
    let db_url = DbConf::init().to_database_url();
    let config = Config::load()?;
    let db = toasty::Db::builder().models(toasty::models!(Book)).connect(&db_url).await?;

    let cli = ToastyCli::with_config(db, config);

    cli.parse_and_run().await?;

    Ok(())
}
```

Update `book_service/Cargo.toml` to add the migration CLI `[[bin]]`.

```toml
[[bin]]
name = "migration"
path = "src/bin/migration.rs"
```

### Add `Toasty.toml`

Add a new file `book_service/Toasty.toml`.

```toml
[migration]
path = "toasty"
prefix_style = "Sequential"
checksums = false
statement_breakpoints = true
```

## Generate & Apply DB Migrations

> [!tip]
> We need to run the local database first. Then, run the migration CLI commands.
> ```
> Commands:
> apply     Apply pending migrations to the database
> generate  Generate a new migration based on schema changes
> snapshot  Print the current schema snapshot file
> drop      Drop a migration from the history
> reset     Reset the database (drop all tables) and optionally re-apply migrations
> help      Print this message or the help of the given subcommand(s)
> ```

Due to our justfiles, we can run the following commands from the project root:

- `just book docker compose up`: to start the local database
- `just book migration`: to see the available commands
- `just book migration generate`: to generate database migrations
- `just book migration apply`: to apply database migrations

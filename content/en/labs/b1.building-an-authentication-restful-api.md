> [!Assignment] In this series,
> We build a production-grade authentication RESTful API server application using OAuth2.1, Argon2, Blake3, Axum, Tokio, Tower, Serde, Toasty ORM, Garde, Utoipa with Docker and PostgreSQL.
> - [Hyper](https://github.com/hyperium/hyper), [Axum](https://github.com/tokio-rs/axum), [Tokio](https://tokio.rs) and [Tower](https://github.com/tower-rs): The most prominent HTTP server ecosystem at the time of writing.
> - [Toasty ORM](https://github.com/tokio-rs/toasty): The most promising Object-Relational Mapper (ORM), built by the creators of Tokio and Axum.
> - [Serde](https://github.com/serde-rs/serde) and [Utoipa](https://github.com/juhaku/utoipa): The most prominent serialization framework and OpenAPI 3.1 specification generator.
> - [Garde](https://github.com/jprochazk/garde): The most promising and most feature-rich validation library in Rust at the time of writing.
